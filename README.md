# Kartik Kumar — Portfolio Web

> High-performance, modern portfolio built completely in **React.js + TypeScript + Vite**, translated and modernized from the original Flutter codebase into pure web technology.

## 🚀 Overview

- **Core Framework**: React 19 + TypeScript + Vite
- **Styling**: Cyberpunk Glassmorphism & Neon Aesthetics (Vanilla CSS)
- **Live APIs**: Alfa LeetCode API integration for live stats & problem solving metrics
- **Responsive**: Fully responsive desktop, tablet, and mobile layouts

---

## 📑 Portfolio Sections

1. **Navbar**
   - Floating glass navigation bar with blur effect and scroll elevation
   - Links: Profile, Experience, Skills, Stats, Achievements, Projects, Contact
   - Glowing avatar brand ring
   - Resume button with direct download / view link
   - Responsive mobile drawer menu

2. **Hero Section (`MyProfile` & About)**
   - Profile photo with continuous spinning animated neon gradient ring
   - Dynamic typewriter role animation (`Systems & AI Software Engineer`, `Cross-Platform Systems Builder`, etc.)
   - Quick statistics pills (844+ LeetCode, 1829 Peak Rating, Top 7.16% Knight)
   - Core capabilities grid (Rust/Tauri, Agentic AI, Chromium internals, Full-Stack, etc.)
   - macOS Terminal Code card (`kartik.config.ts`) with live status indicator

3. **Experience & Skills (Side-by-Side on Desktop)**
   - **Work Experience**: DRDO (INMAS) Internship & Freelance Software Developer, timeline dots, chips, and bullet points
   - **My Skills**: Interactive skill chips categorized into Languages, Frameworks & Technologies, AI & Agentic Systems, and Specializations

4. **Stats & Metrics Section (`StatsMetrics`)**
   - **Platform Rankings**: LeetCode (Knight), Codeforces (Pupil 1269), CodeChef (3-Star 1636), GFG (Rank #1 NITP), Robotics Champion (Machine Mayhem winner), HackerRank (5-Star)
   - **LeetCode Performance**: Solved donut chart, Easy/Medium/Hard breakdown progress bars, 52-week 7-row interactive submission heatmap, badge metrics, and live Alfa LeetCode API data fetching
   - **Streak & Productivity**: 849+ contributions, current streak circular ring, longest streak
   - **GitHub Profile Summary**: Interactive SVG curved area graph, metrics (contributions, 17 public repos, followers)
   - **Top Languages**: SVG donut charts for top languages by repository and by commit lines
   - **Commits Hourly Activity**: 24-hour commit distribution histogram (UTC +5:30)

5. **Achievements Section**
   - Competitive programming badges
   - Awards & Recognitions (Machine Mayhem winner ₹10,000 cash prize, Problem Solving Excellence)
   - Verified Certifications with direct Google Drive credential links (NPTEL IIT Kharagpur, NPTEL IIT Madras, Coding Ninjas)

6. **Projects Section**
   - Filter tabs: All, Desktop & AI Agents, AI & Automation, Web Applications, Robotics & Hardware
   - Expandable project cards with tech tags, key bullet points, live preview links, and GitHub source links

7. **Contact Me Section**
   - Direct Email quick copy card with 1-click clipboard feedback
   - "Shoot an Email" action button
   - Direct social badges (LinkedIn, GitHub, Telegram, Discord, WhatsApp, Instagram, LeetCode, CodeChef, GFG)
   - Footer pills (Built with React & TS, Developed by Kartik, NIT Patna, Open for Roles)

8. **Floating Back-to-Top Button**
   - Appears when scrolled down (>300px)
   - Displays real-time circular scroll progress ring

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
